# NitroGym Reus — web del gimnasio

Web de **NitroGym**, gimnasio en Horts de Miró (Reus). Cliente externo.
Apertura prevista: octubre de 2026.

## Qué hay

- `index.html` — la web, estática y de una sola página.
- `wordpress/` — la misma web preparada para meterla en WordPress.
- `Guia-subir-a-WordPress.pdf` — cómo hacerlo, paso a paso.
- `Palabras-clave-Google-Ads.pdf` — investigación de palabras clave para
  las campañas.
- `video/` — los vídeos de la portada.

## Ojo con los datos

Los datos de prensa que aparecen son reales; **las tarifas y los horarios
son provisionales** hasta que el cliente confirme los definitivos.
